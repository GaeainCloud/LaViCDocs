# Markdown PRD Standard

Use this section order:

1. Document metadata
2. Necessity and goals
3. Users and scenarios
4. Scope (in/out)
5. Functional requirements (`REQ-*` list + per-item details)
6. Non-functional requirements
7. AI boundary and fallback strategy
8. Architecture summary and integration constraints
9. Milestones and release plan
10. Open questions and risk list
11. Traceability matrix (`REQ-*` -> API/tool/test)

Per requirement must include:

- Objective
- Rules
- Exception handling
- Acceptance criteria
- Tracking/observability points
